# Error Analysis

This directory contains projects focused on error analysis in machine learning, including confusion matrices and performance metrics.

## Files

- [0-create_confusion.py](0-create_confusion.py): Function that creates a confusion matrix.
- [1-sensitivity.py](1-sensitivity.py): Function that calculates the sensitivity for each class in a confusion matrix.
- [2-precision.py](2-precision.py): Function that calculates the precision for each class in a confusion matrix.
- [3-specificity.py](3-specificity.py): Function that calculates the specificity for each class in a confusion matrix.
- [4-f1_score.py](4-f1_score.py): Function that calculates the F1 score of a confusion matrix.
- [5-error_handling](5-error_handling): Text file containing recommended approaches for different bias/variance scenarios.
- [6-compare_and_contrast](6-compare_and_contrast): Text file containing the most important issue identified from training and validation confusion matrices.
